# Yven Maison — Landing Page

Landing page interativa desenvolvida sob demanda para a **Yven Maison**, atualmente ativa em produção. O objetivo do projeto foi construir uma vitrine digital rápida, responsiva e focada na apresentação da marca e conversão de clientes.

**Site no ar:** [yven.com.br](https://yven.com.br)

## Sobre o projeto
O site foi projetado para atender às necessidades reais da empresa no segmento de Moda, unindo identidade visual limpa com navegação fluida em dispositivos móveis e desktop.

## Funcionalidades
- Design responsivo adaptado para mobile e desktop.
- Menu Detalhado de Contato.
- Lançamentos de conjuntos em tempo real.
- Estrutura otimizada para carregamento rápido e SEO básico.

## Stack utilizada
- TypeScript
- React
- CSS
- Hospedagem e deploy: Hostinger
